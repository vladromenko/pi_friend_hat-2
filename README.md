# pi_friend_hat-2

A small local voice assistant project built on Raspberry Pi 5 and Hailo AI HAT+.

![alt text](video_photo_test/Photo.jpeg)

The goal of this project was to build a simple local robot assistant that can:
- listen through a microphone,
- convert speech to text,
- generate responses using a local LLM,
- speak responses with text-to-speech,
- run fully on local hardware without cloud APIs.

The project was used as a practical learning environment for local AI, embedded Linux, audio systems, and edge AI acceleration.

---

# Hardware

- Raspberry Pi 5
- Hailo AI HAT+ 2 (Hailo-10H)
- USB microphone
- USB speaker/audio device

---

# Main Technologies

## Local LLM Runtime
- `hailo-ollama`

Used to run optimized Hailo-compatible language models locally on the Raspberry Pi.

Main tested model:
- `qwen2.5-instruct:1.5b`

The model runs directly through the Hailo accelerator instead of cloud inference.

---

## Speech Recognition
- `whisper.cpp`

Used for offline speech-to-text.

Audio from the microphone is recorded into WAV files and then transcribed locally using Whisper.

---

## Text To Speech
- `Piper TTS`

Used for fully offline speech synthesis.

The assistant generates WAV audio responses and plays them through the speaker.

---

## Python Runtime
Main logic is written in Python.

The project controls:
- microphone recording,
- Whisper transcription,
- LLM requests,
- TTS generation,
- audio playback,
- conversation loop.

---

# How The Robot Works

## 1. Audio Recording

The assistant records short audio segments from the microphone.

Main file:
- `audio_input.py`

The project uses:
- `sounddevice`
- ALSA devices

---

## 2. Speech To Text

Recorded audio is passed into `whisper.cpp`.

Main file:
- `speech_to_text.py`

Whisper converts speech into text locally on the Raspberry Pi.

---

## 3. LLM Response Generation

The transcript is sent to the local Hailo LLM server.

Main file:
- `llm_client.py`

The assistant communicates with:
- `http://127.0.0.1:8000/api/generate`

The response is generated by:
- `qwen2.5-instruct:1.5b`

running through:
- `hailo-ollama`

---

## 4. Text To Speech

The generated response is converted into audio using Piper.

Main file:
- `tts.py`

The generated WAV file is then played through the speaker.

---

## 5. Continuous Conversation Loop

Main loop:
- `main.py`

The robot continuously:
1. listens,
2. transcribes,
3. generates a response,
4. speaks,
5. waits for the next input.
